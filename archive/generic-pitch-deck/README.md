## 🌟 주요 기능

### 1. 듀얼 발표 모드 지원
- **📜 웹 스크롤 모드 (Landing Page View)**:
  - 데모데이 방문자, 심사위원, 투자자가 링크를 통해 편하게 스크롤하며 전반적인 사업 계획과 아이템을 검토할 수 있는 고해상도 웹페이지.
  - 문제 제기, 솔루션, 아이템 상세 카드, 시장 성장성 인터랙티브 차트(Chart.js), 비즈니스 모델, 로드맵, 팀 소개.
- **📺 전체화면 슬라이드 발표 모드 (Presentation Slide Deck)**:
  - 상단 **[📺 슬라이드 발표 모드 시작]** 버튼 또는 키보드 **`F`** 키를 누르면 즉시 전체화면 슬라이드로 전환.
  - 키보드 방향키(`←`, `→`), 스페이스바(`Space`)로 슬라이드 넘김.
  - **발표 타이머** 내장: 5분/10분 피치 세션 시간 관리.
  - **발표자 큐카드 메모(`N` 키)**: 슬라이드마다 준비된 발표 스크립트 실시간 확인 가능.

### 2. 💡 아이템 즉시 주입 준비 완료
- 채팅창에 **"이 아이템으로 바꿔줘"** 또는 **"새 아이템 추가해줘"**라고 아이템 정보(이름, 설명, 특징)를 말씀해주시면 즉시 반영해 드립니다.
- 웹사이트 내 **[아이템 등록]** 버튼을 통해 직접 웹 브라우저에서 실시간으로 추가하실 수도 있습니다.
- 소스 코드에서 수정 시 `items-data.js` 파일만 수정하면 웹사이트와 슬라이드 전체에 자동으로 반영됩니다.

## 📁 파일 구조

- **`index.html`**: 웹사이트 및 발표 슬라이드 전체 구조 마크업
- **`items-data.js`**: 발표 제목, 발표자, 문제점, 솔루션, **핵심 아이템 목록**, 시장 데이터 등이 정의된 모듈형 데이터 파일
- **`app.js`**: 슬라이드 전환, 타이머, 키보드 단축키, 차트 렌더링, 모달 팝업 컨트롤러
- **`style.css`**: 글래스모피즘(Glassmorphism), 네온 글로우, 슬라이드 애니메이션 스타일링
