# TODAY DATE — 프로젝트 소개 홈페이지

> 오늘 예약하고, 오늘 만나는 새로운 인연.
> 매칭이 확정된 순간, 오늘의 만남이 시작됩니다.

당일 예약형 오프라인 1:1 소개팅 서비스 **TODAY DATE**의 창업 아이디어 발표용 소개 페이지입니다.
**실제 예약·결제 기능은 없습니다.** 시간표, 신청 흐름, 매출 계산기는 모두 시연용(가정치)입니다.

## 파일 구조

```
index.html          메인 페이지 (10개 섹션)
css/style.css       디자인 시스템 · 반응형 스타일
js/script.js        내비게이션, 시연용 시간표/신청 흐름, 가정치 계산기
assets/hero.jpg     히어로 이미지 (약 110KB)
.nojekyll           GitHub Pages가 Jekyll 처리 없이 그대로 배포하도록 설정
archive/            이전 범용 발표 템플릿 (사용하지 않음, 보관용)
```

## 실행 방법

- `index.html`을 더블 클릭해 브라우저에서 엽니다. 빌드나 설치 과정은 필요 없습니다.
- 폰트(Pretendard, Noto Serif KR)는 CDN에서 불러오므로 인터넷이 연결되어 있어야 디자인이 의도대로 표시됩니다.

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소에 push 합니다.
2. 저장소 **Settings → Pages**로 이동합니다.
3. **Source**: `Deploy from a branch`, **Branch**: `main` / `(root)` 선택 후 Save.
4. 1~2분 후 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속합니다.

## 🎙️ 발표 도우미 (Presenter Assistant) & 전체화면 기능

발표 현장에서 프로젝터나 대형 모니터로 시연할 때 바로 활용할 수 있는 발표 전용 보조 시스템이 내장되어 있습니다.

### 1. 주요 기능
- **전체화면 (Fullscreen)**: 상단 헤더의 `전체화면 [F]` 버튼 또는 하단 컨트롤러 클릭
- **발표 도우미 큐카드 (HUD)**:
  - 10개 섹션 전체에 대한 **핵심 전달 포인트**, **구어체 발표 대본**, **심사위원 예상 질문 & 답변 전략** 제공
  - 화면 스크롤 시 현재 보고 있는 섹션의 대본으로 **실시간 자동 동기화**
  - 대본 원클릭 복사 버튼 및 글자 크기(A-, A+) 조절 지원
- **피치 타이머**: 3분(숏 피치) / 5분(표준) / 10분(심층) 프리셋 및 카운트업 타이머 (1분 미만 시 경고 색상 표시)
- **가상 레이저 포인터**: 마우스 커서를 붉은빛 레이저 포인터로 전환하여 스크린 강조 가능
- **섹션 퀵 내비게이터**: 하단 독에서 `[04 / 10 · TIME-BASED BOOKING]` 형태로 현재 위치 표시 및 원클릭 점프

### 2. 키보드 단축키
| 단축키 | 기능 |
| --- | --- |
| <kbd>F</kbd> | **전체화면** 진입 / 해제 |
| <kbd>N</kbd> | **발표 도우미 큐카드** 열기 / 닫기 |
| <kbd>T</kbd> | **발표 타이머** 시작 / 일시정지 |
| <kbd>R</kbd> | 타이머 초기화 (00:00) |
| <kbd>L</kbd> | **가상 레이저 포인터** 켜기 / 끄기 |
| <kbd>→</kbd> 또는 <kbd>PageDown</kbd> | 다음 섹션으로 부드럽게 이동 |
| <kbd>←</kbd> 또는 <kbd>PageUp</kbd> | 이전 섹션으로 부드럽게 이동 |
| <kbd>ESC</kbd> | 도우미 패널 닫기 또는 레이저 포인터 끄기 |
